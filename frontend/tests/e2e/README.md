# 🎭 E2E Тесты (Playwright)

**Статус:** ✅ 19 сценариев готово

## 📋 Описание

E2E тесты для проверки критических сценариев использования CGM Dashboard.

## 🚀 Запуск тестов

### Предварительные требования

1. **Установить Playwright:**
```bash
npx playwright install --with-deps chromium
```

2. **Запустить dev сервер:**
```bash
# В одном терминале
npm run dev
```

### Запуск тестов

```bash
# Все тесты (headless)
npm run test:e2e

# В браузере (headed)
npm run test:e2e:headed

# UI режим (интерактивно)
npm run test:e2e:ui

# Конкретный файл
npx playwright test tests/e2e/dashboard.spec.ts

# Конкретный браузер
npx playwright test --project=chromium
```

## 🔧 Troubleshooting

### Тесты не запускаются

**Проблема:** `Error: Cannot connect to server`

**Решение:**
```bash
# Запустить dev сервер
npm run dev

# В другом терминале запустить тесты
npm run test:e2e
```

### Тесты падают с timeout

**Проблема:** `TimeoutError: Timeout 30000ms exceeded`

**Решение:**
1. Проверить, что backend запущен
2. Увеличить timeout в `playwright.config.ts`
3. Запустить с `--debug` флагом
