## 🎨 Изменение 1: Скрытая панель активных фильтров по умолчанию

### Проблема

При первоначальной загрузке карты отображались **сотни чипов** в панели активных фильтров:
- 85 регионов
- 100+ поставщиков
- 50+ продуктов

Это закрывало большую часть экрана и выглядело неэстетично.

![Проблема](https://via.placeholder.com/800x400/ff6b6b/ffffff?text=Было:+сотни+чипов+закрывают+экран)

### Решение

Панель активных фильтров показывается **только если выбраны не все** доступные значения.

**Логика:**
```typescript
// Не считаем активными фильтрами значения по умолчанию
const isYearsFiltered = selectedYears.length > 0 && selectedYears.length < availableYears.length;
const isRegionsFiltered = selectedRegions.length > 0 && selectedRegions.length < availableRegions.length;
const isSuppliersFiltered = selectedSuppliers.length > 0 && selectedSuppliers.length < availableSuppliers.length;
const isProductsFiltered = selectedProducts.length > 0 && selectedProducts.length < availableProducts.length;

const hasActiveFilters = isYearsFiltered || isRegionsFiltered || isSuppliersFiltered || isProductsFiltered;
```

**Файл:** `frontend_map/src/App.tsx` (строки 73-82)

### Результат

| Ситуация | Поведение |
|----------|-----------|
| Загрузка карты (выбрано 85/85 регионов) | ❌ Панель **скрыта** |
| Пользователь выбрал 5 регионов | ✅ Панель **показана** с 5 чипами |
| Выбраны все поставщики (100/100) | ❌ Панель **скрыта** |
| Выбрано 10 поставщиков из 100 | ✅ Панель **показана** |

![Решение](https://via.placeholder.com/800x400/51cf66/ffffff?text=Стало:+панель+скрыта+при+загрузке)

## 📅 Изменение 2: Исправлен фильтр «Год»

### Проблема

В фильтре «Год» **2024 год не отображался** в выпадающем списке.

**Причина:** В `renderOption` первая опция (2024) заменялась на кнопку «Выбрать всё»:

```tsx
// ❌ НЕПРАВИЛЬНО (до исправления)
const isFirstOption = option === availableYears[0];

if (isFirstOption) {
  return (
    <Box key="select-all">
      Выбрать всё
    </Box>
  );
}

// 2024 год никогда не отображался!
```

### Решение

Удалена логика замены первого года на кнопку «Выбрать всё».

**Файл:** `frontend_map/src/components/HeaderFilters.tsx` (строки 120-132)

```tsx
// ✅ ПРАВИЛЬНО (после исправления)
renderOption={(props, option, { selected }) => (
  <li {...props}>
    <input
      type="checkbox"
      checked={selected}
      onChange={(e) => {
        e.stopPropagation();
        toggleYear(option);
      }}
      style={{ marginRight: 8, accentColor: '#3388ff' }}
    />
    {option}
  </li>
)}
```

### Результат

| До | После |
|----|-------|
| ❌ 2024 год не отображался | ✅ Все годы отображаются |
| Кнопка «Выбрать всё» заменяла 2024 | ✅ Кнопка «Выбрать всё» удалена |

**Выпадающий список теперь:**
```
☑ 2024
☑ 2025
☑ 2026
...
```

## 🎯 Рекомендации по использованию

### Для пользователей

- **По умолчанию:** Все фильтры показывают все данные (панель скрыта)
- **Для фильтрации:** Выберите конкретные значения в dropdown
- **Для сброса:** Нажмите кнопку ❌ (Сбросить фильтры)

### Для разработчиков

**Если нужно показать панель всегда:**
```typescript
// Измените логику в App.tsx
const hasActiveFilters = true; // Всегда показывать
```

**Если нужно скрыть панель полностью:**
```typescript
const hasActiveFilters = false; // Никогда не показывать
```
