## 📋 Проблема

При экспорте данных в CSV и открытии файла в Excel отображались "кракозябры" вместо русских букв.

**Причина:** 
- CSV файл создавался в кодировке UTF-8 **без BOM** (Byte Order Mark)
- Excel по умолчанию открывает CSV в кодировке Windows-1251 (ANSI)
- Без BOM Excel не распознаёт UTF-8 кодировку

## 🎯 Как это работает

### BOM (Byte Order Mark):

- **Что это:** Специальный символ `\uFEFF` в начале файла
- **Зачем:** Сигнализирует программе о кодировке файла
- **Для Excel:** Позволяет автоматически распознать UTF-8

### Алгоритм экспорта:

1. **Формирование CSV:**
   ```typescript
   const csv = [
     headers.join(','),
     ...csvRows.map((row) => row.join(',')),
   ].join('\n');
   ```

2. **Добавление BOM:**
   ```typescript
   const BOM = '\uFEFF';
   const blob = new Blob([BOM + csv], { type: 'text/csv;charset=utf-8;' });
   ```

3. **Скачивание файла:**
   ```typescript
   link.download = `cgm_comparison_regions_${date}.csv`;
   ```

4. **Открытие в Excel:**
   - Excel видит BOM
   - Распознаёт UTF-8 кодировку
   - Корректно отображает кириллицу ✅

## 💡 Технические детали

### Почему BOM работает:

1. **BOM = `\uFEFF`:**
   - Специальный Unicode символ
   - Не отображается в тексте
   - Служит маркером кодировки

2. **Excel распознаёт:**
   - `EF BB BF` (UTF-8 BOM) → UTF-8
   - `FF FE` (UTF-16 LE BOM) → UTF-16 LE
   - `FE FF` (UTF-16 BE BOM) → UTF-16 BE
   - Нет BOM → ANSI (по умолчанию)

3. **Другие программы:**
   - **Блокнот:** Распознаёт BOM автоматически
   - **VS Code:** Определяет кодировку по BOM
   - **LibreOffice:** Спрашивает кодировку (BOM помогает)


### Колонки:

| № | Название | Описание |
|---|----------|----------|
| 1 | Регион | Название региона |
| 2 | Период А (сумма) | Сумма закупок за период А |
| 3 | Период Б (сумма) | Сумма закупок за период Б |
| 4 | Период А (контракты) | Количество контрактов за период А |
| 5 | Период Б (контракты) | Количество контрактов за период Б |
| 6 | Изменение (сумма) | Абсолютное изменение суммы |
| 7 | Изменение (%) | Процентное изменение |
| 8 | Тренд | growth/decline/stable |

## 📞 Поддержка

При возникновении проблем:

1. **Excel показывает кракозябры:**
   - Проверьте, что BOM добавлен
   - Откройте через "Данные → Из текста/CSV"
   - Выберите кодировку UTF-8 вручную

2. **Файл не открывается:**
   - Проверьте расширение (.csv)
   - Убедитесь, что файл скачался полностью

3. **Данные некорректны:**
   - Проверьте разделитель (запятая)
   - Убедитесь, что в Excel правильный региональный формат
