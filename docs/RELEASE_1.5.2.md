## 🎯 Обзор выпуска

Версия 1.5.2 содержит критические исправления для доступа к дашборду карты регионов (frontend_map) по локальной сети.

**Проблемы предыдущих версий:**
- ❌ frontend_map не работал при доступе с других устройств
- ❌ Ошибки 404 из-за дублирования пути `/api`
- ❌ Ошибки подключения к backend при сетевом доступе

---

## 🔧 Исправления

### 1. Доступ к frontend_map по локальной сети

**Проблема:**
- При доступе `http://192.168.x.x:5174` с другого компьютера запросы API не работали
- Ошибки: `ERR_CONNECTION_REFUSED`, `Network error: Backend недоступен`

**Причина:**
```typescript
// frontend_map/src/api/client.ts (БЫЛО)
const API_BASE_URL = import.meta.env.VITE_API_URL || '';
```

**Решение:**
```typescript
// frontend_map/src/api/client.ts (СТАЛО)
const API_BASE_URL = '/api';
```

**Результат:**
- ✅ Все запросы идут через Vite proxy
- ✅ Backend доступен на вашем компьютере
- ✅ Все устройства работают через ваш компьютер

---

### 2. Дублирование пути `/api` в mapApi.ts

**Проблема:**
- После исправления client.ts появились ошибки 404
- URL: `/api/api/map/regions` вместо `/api/map/regions`

**Причина:**
```typescript
// client.ts
const API_BASE_URL = '/api';  // ✅

// mapApi.ts (БЫЛО)
const response = await apiClient.get('/api/map/regions', ...);
//                                      ^^^^
//                           Дублирование!
```

**Решение:**
```typescript
// mapApi.ts (СТАЛО)
const response = await apiClient.get('/map/regions', ...);
//                                      ^^^^^^^^^^^^^^^
//                           Без /api
```

**Изменённые функции:**
1. `getRegions()` — `/api/map/regions` → `/map/regions`
2. `getYears()` — `/api/filters/years` → `/filters/years`
3. `getRegionsList()` — `/api/filters/regions` → `/filters/regions`
4. `getSuppliers()` — `/api/filters/suppliers` → `/filters/suppliers`
5. `getProducts()` — `/api/filters/products` → `/filters/products`
6. `getRegionSuppliers()` — `/api/map/regions/...` → `/map/regions/...`
7. `getRegionCategories()` — `/api/map/regions/...` → `/map/regions/...`
