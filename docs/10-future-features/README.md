## 🎯 Критерии добавления в эту папку

Функция попадает в эту папку, если:

1. **Не критична для текущей версии** — проект работает без неё
2. **Требует значительных изменений** — > 2 часов работы
3. **Усложняет интерфейс** — требует отдельных компонентов
4. **Опциональна для пользователя** — не все будут использовать
