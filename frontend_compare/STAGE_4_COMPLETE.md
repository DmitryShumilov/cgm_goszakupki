## 🎨 Компонент PeriodColumn

### Пропсы

```typescript
interface PeriodColumnProps {
  period: 'A' | 'B';
  title: string;      // "Ⓐ Период А" / "Ⓑ Период Б"
  color: string;      // "#3388ff" / "#ff6b6b"
}
```

### Функционал

- **Годы:** Сетка кнопок с мультивыбором
- **Регионы:** Скроллируемая область с кнопками (до 20 показывается, остальные скрываются)
- **Продукты:** Скроллируемая область с кнопками
- **Сброс фильтров:** Кнопка сброса всех фильтров периода

### Стили

- Градиентный фон с цветовым кодированием
- Активные кнопки с подсветкой и тенью
- Hover эффекты с увеличением тени
- Обрезка длинных названий (25 символов для регионов, 20 для продуктов)

---

## 🎨 Компонент PeriodFilters

### Назначение

Контейнер для двух колонок фильтров с заголовком и кнопкой обмена

### Функционал

- **Заголовок:** "📊 Режим сравнения периодов"
- **Кнопка обмена:** SwapButton для быстрой замены периодов местами
- **Две колонки:** PeriodColumn для периода А и Б
- **Индикатор фильтров:** Панель с текущими выбранными значениями

### Автозагрузка данных

При монтировании компонента автоматически загружаются:
- Доступные годы (`/api/filters/years`)
- Доступные регионы (`/api/filters/regions`)
- Доступные продукты (`/api/filters/products`)

## 🎨 Компонент SwapButton

### Пропсы

Нет (использует Zustand store напрямую)

### Функционал

- **Анимация:** Поворот иконки 🔄 на 180° при клике
- **Disabled состояние:** Кнопка блокируется на время анимации (300ms)
- **Tooltip:** "Поменять периоды местами"

### Стили

- Контурная кнопка с полупрозрачной границей
- Hover эффект с увеличением масштаба (scale 1.05)
- Полупрозрачный фон при наведении

| Период | Цвет | HEX |
|--------|------|-----|
| **Период А** | Синий | `#3388ff` |
| **Период Б** | Красный | `#ff6b6b` |
| **Рост** | Зелёный | `#38EF7D` |
| **Падение** | Красный | `#FF6B6B` |
| **Стабильно** | Жёлтый | `#FFD93D` |

### Градиенты

```css
/* Фон колонки периода */
background: linear-gradient(135deg, ${color}15 0%, ${color}05 100%);

/* Активная кнопка */
background: linear-gradient(135deg, ${color} 0%, ${color}cc 100%);

/* Glassmorphism эффект */
backdrop-filter: blur(10px);
```

### Тени и свечение

```css
/* Тень активной кнопки */
box-shadow: 0 0 15px ${color}80;

/* Hover эффект */
box-shadow: 0 0 25px ${color};
```
