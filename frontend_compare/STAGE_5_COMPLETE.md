## 🎨 Компонент KpiComparisonCard

### Пропсы

```typescript
interface KpiComparisonCardProps {
  label: string;         // Название метрики
  icon: string;          // Emoji иконка
  periodAValue: number;  // Значение периода А
  periodBValue: number;  // Значение периода Б
  change: ChangeData;    // Данные об изменении
  isMoney?: boolean;     // Форматировать как деньги
}
```

### Функционал

- **Отображение значений:** Два значения (Период А / Период Б)
- **Процентное изменение:** С иконкой тренда (📈/📉/➡️)
- **Абсолютное изменение:** В скобках с единицами измерения
- **Цветовая индикация:** Зелёный (рост), Красный (падение), Жёлтый (стабильно)
- **Glassmorphism 2.0:** Градиентный фон с матовым стеклом
- **Hover эффект:** Подъём и увеличение масштаба
- **Декоративное свечение:** Радиальный градиент в углу

### Форматирование чисел

```typescript
// Деньги
1,000,000,000 → "1.00 млрд ₽"
1,000,000     → "1.00 млн ₽"
1,000         → "1 тыс ₽"

// Числа
1,000,000     → "1 000 000"
1,000         → "1 000"
```
