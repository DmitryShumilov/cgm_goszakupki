## 🎨 Компонент ComparisonDynamicsChart

### Тип диаграммы
**Composed Chart** (Bar + Bar) — два набора столбцов для сравнения

### Функционал
- **Группировка столбцов:** Период А (синий) и Период Б (красный) рядом
- **Ось X:** Месяцы (YYYY-MM формат)
- **Ось Y:** Сумма закупок (автоматическое форматирование)
- **Tooltip:** Детальная информация при наведении
- **Легенда:** Цветовая индикация периодов
- **Адаптивность:** ResponsiveContainer с автоматическим масштабированием

### Данные
```typescript
{
  labels: ["2024-01", "2024-02", ..., "2024-12"],
  periodA: { amounts: [...], quantities: [...] },
  periodB: { amounts: [...], quantities: [...] }
}
```

## 🎨 Компонент ComparisonRegionsChart

**Horizontal Bar Chart** — горизонтальные столбцы

- **Горизонтальная ориентация:** Удобно для длинных названий регионов

### Данные
```typescript
{
  labels: ["Москва", "СПб", ...],
  periodA: { amounts: [...], counts: [...] },
  periodB: { amounts: [...], counts: [...] }
}
```

## 🎨 Компонент ComparisonScatterPlot

### Тип диаграммы
**Scatter Plot** — точки на плоскости

### Функционал
- **Ось X:** Период А (сумма)
- **Ось Y:** Период Б (сумма)
- **Диагональ равенства:** Пунктирная линия y=x
- **Цветовая кодировка точек:**
  - 🟢 Зелёный (#38EF7D): Рост (>5%)
  - 🔴 Красный (#FF6B6B): Падение (<-5%)
  - 🟡 Жёлтый (#FFD93D): Стабильно (±5%)
- **Интерпретация:**
  - **Выше диагонали:** Рост закупок
  - **Ниже диагонали:** Падение закупок
  - **На диагонали:** Без изменений

### Легенда
- 📈 Рост
- 📉 Падение
- ➡️ Стабильно

## 🎨 Компонент ComparisonTable

### Тип компонента
**Material-UI Table** с сортировкой и экспортом

### Функционал
- **Сортировка:** По клику на заголовок столбца
- **Столбцы:**
  1. Регион (сортировка)
  2. Период А (сумма, сортировка)
  3. Период Б (сумма, сортировка)
  4. Контракты (А → Б)
  5. Изменение (сумма, сортировка)
  6. Изменение (%), сортировка)
  7. Тренд (иконка)
- **Экспорт в CSV:** Кнопка Download
- **Итоговая строка:** Количество регионов + статистика трендов
- **Цветовая индикация:**
  - Зелёный: Положительное изменение
  - Красный: Отрицательное изменение
  - Иконка тренда: 📈/📉/➡️

### Сортировка
```typescript
type OrderBy = 'region' | 'periodA_amount' | 'periodB_amount' | 'absoluteDiff' | 'percentDiff';
```
